# 常见问题

## 1. 打开某些界面时一闪而过，之后侧边栏、悬浮窗再也打不开

多见于<b>前台保活模式</b>：打开的界面包含系统设置、授权页、部分 ROM 的分身选择等
敏感界面时，前台服务会被系统掐掉。改用<b>无障碍保活</b>
（设置 → 通知与保活 → 保活方式）。

## 2. 点开应用后直接全屏了

确认 LSPosed 里勾选了<b>系统框架</b>并重启。小窗靠引擎在 `system_server` 里接管任务，
没勾系统框架就只是普通启动。

## 3. 无法打开小窗 / 卡在引导 / 一开就闪退

先检查是不是开过 Vulkan（例如「使用 Vulkan 进行 HWUI 渲染」）。Z-Flow 不支持 Vulkan，
关掉该选项后强行停止 Z-Flow 再运行。引导页里的红色提示就是这一条。

## 4. 应用界面没填满小窗，像 Windows 窗口

系统设置 → 开发者选项 → 关闭「强制使用桌面模式」。

## 5. Z-Flow 掉后台

定制 ROM 常见。给 Z-Flow 加锁、允许自启动，或切换保活方式（前台服务 / 无障碍）。

## 6. 小窗太大/太小，想调缩放

设置里已经没有缩放项了：那批键（缩放、迷你比例、变暗、贴边比例）只接给已删除的
经典虚拟屏内核，留着只会「调了没反应」。现在窗口大小由引擎默认值决定，
**长按窗口边缘**即可调整；「运行规则与交互 → 贴边」里的滑杆只影响贴边图标露出多少。

## 7. 横屏应用显示异常

设置 → 运行规则与交互 → 横屏应用，把需要横屏的应用加进去；
「横屏分享」打开时，横屏小窗会与桌面共享窗口，不会再单独占一块。
